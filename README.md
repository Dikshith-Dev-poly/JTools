## 🧠 About the Project

**JTool** is a multi-utility web application designed to solve everyday problems directly in the browser.
From image editing to password generation and CSV parsing — everything runs client-side with optimized performance and clean architecture.

💡 Built with a strong focus on:

* Performance ⚡
* Clean architecture 🧱
* Real-world problem solving 🛠️
* Deep understanding of core JavaScript

---

## 🛠️ Tech Stack

* **HTML5** — Structure
* **CSS3** — Styling & Animations
* **Vanilla JavaScript (ES6+)** — Logic & Functionality

🚫 No frameworks, no external libraries — everything is built from scratch.

### 🏠 Home Page

* 🔍 Search with **debounce optimization**

## 🖼️ Image Editor (Advanced Canvas Engine)

A fully functional image editor built using the **Canvas API**:

* 📂 Image upload + drag & drop
* ✂️ Crop (multiple aspect ratios)
* 🔄 Rotate (left/right)
* 🔁 Flip (horizontal & vertical)
* 🎛️ Adjustments:
  * Brightness
  * Contrast
  * Saturation
* 🎨 Filters:
  * Blur
  * Grayscale
  * Invert
  * Emboss
  * Edge Detection
* 💾 Export as **PNG / JPEG with quality control**

📌 Built using low-level pixel manipulation (`getImageData`) and transformations.

---

## 🌦️ Weather App

* 🌍 Real-time weather using API
* ⚡ Optimized with **LRU Cache + Expiry Strategy**
* 🔄 Dynamic content rendering
* 📉 Reduced redundant API calls

---

## 🔐 Password Generator

* 🔢 Length: 4–64
* 🔤 Uppercase / Lowercase
* 🔢 Numbers
* 🔣 Symbols
* 🎲 Secure randomness using **Fisher-Yates Shuffle**
* 📊 Strength indicator:
  * Entropy calculation
  * Pool size
* 📋 Copy to clipboard (Clipboard API)

---

## 🔊 Text-to-Speech Engine

* 🎤 Convert text to speech using Web Speech API
* 🎚️ Controls:
  * Speed
  * Pitch
  * Volume
  * ▶️ Playback controls:
    * Speak / Pause / Resume / Stop
  * 🌐 Voice selection (all available voices)
  * 🔁 State management for playback

---

## 🧩 Sudoku Solver

* 🧠 Built using **Backtracking + Recursion + DFS**
* ⚡ Optimized with **Bitmasking**
* 🎮 Difficulty modes:
  * Easy
  * Medium
  * Hard
* ✔️ Ensures valid single-solution puzzles

---

## 📊 CSV Viewer (High Performance)

* 📂 Drag & Drop CSV upload
* ⚡ Large file handling using:
  * **Web Workers** (no UI blocking)
  * Streaming & chunk processing
* 📄 Pagination for large datasets
* 🔍 Efficient indexing system
* 🎨 Smooth UI with mouse interaction effects
